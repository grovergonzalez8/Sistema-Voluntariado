# ADR 0010: Licencia pendiente

- Estado: aceptado
- Fecha: 2026-07-23

## Contexto

El propietario no ha elegido términos legales de distribución.

## Decisión

Marcar paquetes `UNLICENSED` y proyecto privado; no crear archivo de licencia.

## Alternativas

Elegir una licencia abierta sin autorización.

## Consecuencias

No se concede permiso de redistribución; la decisión queda visible.

## Riesgos

Ambigüedad para colaboradores. Resolver antes de distribución externa.
