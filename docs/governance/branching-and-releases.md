# Ramas, commits y releases

- Ramas de trabajo breves con prefijos `feat/`, `fix/`, `docs/`, `test/`, `ci/` o `chore/`; las ramas creadas por Codex usan `codex/` salvo instrucción contraria.
- Commits pequeños con Conventional Commits y sin reescribir historia compartida.
- Pull request con controles verdes, revisión humana y cambios de esquema visibles.
- Sin despliegue automático a producción en esta fase.
- Versiones futuras seguirán SemVer cuando exista una primera release; `CHANGELOG.md` conserva `Unreleased`.

No se configura remoto ni estrategia de entornos definitiva dentro de este bootstrap.
