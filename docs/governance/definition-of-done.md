# Definition of Ready y Done

## Ready

- Problema, actor, resultado y fuera de alcance están explícitos.
- Reglas desconocidas figuran como preguntas, no como supuestos ocultos.
- Riesgos de datos y permisos están identificados.
- Existe criterio observable y estrategia de pruebas.
- Un ExecPlan cubre cambios de varias capas o infraestructura.

## Done

- Código, migraciones y documentación describen el mismo comportamiento.
- Formato, lint, límites, typecheck, unitarias, integración y build pasan.
- SQL/RLS y E2E pasan cuando aplican; todo bloqueo ambiental queda evidenciado.
- No hay secretos, datos reales ni patrones prohibidos.
- Dependencias tienen uso, lockfile revisado y CI equivalente.
- Revisiones de arquitectura, seguridad, QA y documentación están resueltas.
- ExecPlan y changelog registran el resultado; existe revisión humana.
