# Matriz de responsabilidades

| Área                        | Propietario de decisión  | Revisión obligatoria       |
| --------------------------- | ------------------------ | -------------------------- |
| Producto y datos capturados | Propietario del producto | Seguridad/privacidad       |
| Arquitectura y límites      | Mantenimiento técnico    | Architect                  |
| Migraciones y RLS           | Mantenimiento de datos   | Database security reviewer |
| UX y accesibilidad          | Equipo web               | QA/producto                |
| Calidad y CI                | Mantenimiento técnico    | QA reviewer                |
| Documentación y ADR         | Autor del cambio         | Docs governor              |
| Releases y secretos         | Propietario autorizado   | Seguridad/operaciones      |

Los nombres de personas/equipos concretos quedan pendientes; `CODEOWNERS.example` no inventa usuarios.
